# Contributing

Thanks for helping. This repository holds documentation and client configs for a hosted MCP server; the
server code is not here.

- **Found a wrong step or a config that no longer works?** Open an issue with the client name and version, or
  send a pull request that fixes the file.
- **Want a new capability?** Open a feature request issue and describe the job you want done.
- **Security issue?** Do not open a public issue. See [SECURITY.md](SECURITY.md).

Keep changes factual: every claim should match what the server does today. Never commit tokens, account ids or
customer data.
